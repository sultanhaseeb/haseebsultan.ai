# Homepage implementation

The supplied brief defines this single-page static Astro website. The visual direction is a light editorial engineering portfolio: near-white canvas, ink typography, restrained blue accents, thin borders, natural square portrait, and generous spacing. Infrastructure experience remains the foundation of the AI focus.

- Build semantic Astro components for the header, hero, topics, writing, projects, journey, work areas, learning, and footer.
- Use TypeScript content data and one social-link configuration; mark article and project entries as previews without inventing published pages or achievements.
- Keep navigation available on mobile without JavaScript. Anchor homepage links to their corresponding sections.
- Use Tailwind v4 utilities alongside shared CSS tokens and responsive layout rules. Keep the full photo composition at `public/images/haseeb.jpg`.
- Supply canonical, Open Graph, X, Person structured data, favicon, robots, sitemap, and Cloudflare static asset configuration.
- Verify with Astro type checks, a production build, and a local HTTP request. Document installation, maintenance, and later deployment. No browser automation or deployment is requested.
